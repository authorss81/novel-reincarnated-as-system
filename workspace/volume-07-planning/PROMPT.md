## The hard rules to carry into every Volume 7 batch prompt, restated once

- Close third on Ning Yan for every external scene. **Every sentence Yuan speaks is written in the present tense,
  and no other character is ever in a marked present frame** — with the standing ch 57 exception about completed
  third-person events.
- **At most one bracketed layer line per chapter**, on its own line, in square brackets, never bold, never italics,
  never a heading. They announce; they never explain and they never advise. **Volume 7's bracket budget is set in
  `outline/volume-07.md` and is a number, not an aspiration.**
- Chapter markdown: title heading, optional section headings, plain paragraphs, scarce bold or italic. **No
  blockquotes, no code fences, no tables, no horizontal rules.** Two to four sentences a paragraph; break over
  about 90 words; never over about 120.
- **Close every speech** — `text.count('“') == text.count('”')` in every file — **and use curly apostrophes.**
- **Titles are names**, three to twelve words, under about ninety characters, unique against all 359 existing
  headings and against each other. No weather, no clock time, no date, no age, nothing restating the scene beside it.
- **No authorial scaffolding at all** — *this chapter*, *this volume*, *this book*, *the rest of the book*, *the
  reader*, *in this batch*, *another batch*, *N volumes*. **Count by grep before claiming zero and write the true
  number into the continuity block.**
- **No named weekday, no named calendar month, no named week.**
- **No construction budget that records zero while instances stand on the page.** Walk Volume 6 Batch 0004's
  budget in `state/continuity.md` and Volume 6's own construction rows before drafting and name every carried
